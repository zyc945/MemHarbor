状态：本页的 32 题 A/B/C 对照评测尚未执行。已完成的独立 T0 和原生 Codex 首次使用场景见[新用户验收](NEW-USER.md)，不能替代这里的完整对照。官方 MCP 客户端脚本只验证协议与服务行为；服务报告不填写 Agent 成功率、拒答率或 token 指标。

固定合成材料与 32 个任务见 [quality.json](../../test/fixtures/quality.json)。每个 case 的 task 表示应核对的行为；对引用不可达、冲突、授权纠错等情形，评测者需提供相应合成工具返回和用户授权，不接入真实 vault 或扫描工作区。初始数据与源 fixture 保持一份；每个试验重置到相同初始状态。

| 条件 | 固定材料 |
| --- | --- |
| A 原有流程 | [原 Skill](../../test/fixtures/original-skill.md) 与 faa989e 归档内的原工具说明，关闭正文索引 |

记录模型精确版本、客户端版本、Skill 与代码 commit、日期、相同的上下文/token 预算、相同的最大调用数、轮数和停止条件。预算数值在运行前填写，三条件一致；不在看到结果后修改预期。控制条件采用相同的解码配置并记录多次运行，不用单次人工演示概括模型能力。

逐案例记录：输入、预期结论及证据、实际答案、调用数、是否使用过时事实/混淆环境/编造来源、是否合理拒答、是否未经授权写入、是否保留纠错后的有效修改、可测的 token 消耗及版本信息。没有 token 计量时单列响应字节，不换算成 token。只有已核实的实际结果才计为完成。

来源纠错还需检查一个来源影响多个结论、独立有效来源、后续有效修改、无来源标注和未检查区域。结果不得用归档或 reset 冒充隔离/清除；不可达引用不能自动视为错误。

交付汇总包含各条件任务成功率、过时事实误用、合理拒答、调用数与成本，并附失败案例和未覆盖范围。此表当前没有真实模型结果，不能用服务 Recall@5 代替，也不能称为完成 LoCoMo/LongMemEval 官方基准。
